## 판정

- HTTP 오류는 없었지만 확장 후 전체 p95가 잠정 목표 1초를 크게 초과했다.
- 요청이 느려지면서 미완료 요청이 겹쳐 최대 동시 처리 요청이 3건에서 16건으로 증가했고, 처리량은 약 20% 감소했다.
- 단일 사용자 프로파일에서 PM 과제 목록은 과제 2,000건을 반환하면서 2,002개 SQL을 실행하고 약 2.06 MB를 응답했다. 목록 API의 페이지네이션 부재와 데이터 건수에 비례하는 추가 조회가 주 병목으로 판단된다.
- 우선 개선 대상은 과제 목록 serializer/queryset의 N+1 제거와 목록 페이지네이션이다. 요구사항·프로젝트·대시보드 조회도 같은 방식으로 점검해야 한다.
- 전체 및 경로별 p95는 원시 요청 CSV에 nearest-rank 방식을 적용했다. 표본이 적은 경로별 p95는 참고값이다.
