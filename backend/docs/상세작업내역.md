### STEP 3: 공통코드(Common Code) 모듈 설계 및 DB 마이그레이션
* **작업일 : 2026-08-26**

* **`common` 앱 및 단일 계층형 공통코드 모델 구현**
  * `python manage.py startapp common` 실행 및 `config/settings.py`의 `INSTALLED_APPS`에 등록
  * DB 담당자 스키마 설계에 맞춘 `common/models.py` 내 `CommonCode` 모델 작성

```python
from django.db import models

class CommonCode(models.Model):
    code_id = models.AutoField(primary_key=True, verbose_name="공통 코드 ID")
    large_code = models.CharField(max_length=50, verbose_name="대분류 코드", help_text="예: TASK, PROPOSAL, SKILL 등")
    medium_code = models.CharField(max_length=50, verbose_name="중분류 코드", help_text="예: STATUS, PRIORITY, BACKEND 등")
    small_code = models.CharField(max_length=50, verbose_name="소분류 코드", help_text="예: BACKLOG, LOW, PYTHON 등")
    code_name = models.CharField(max_length=100, verbose_name="코드 이름", help_text="화면 표시용 한글명")
    note = models.CharField(max_length=500, null=True, blank=True, verbose_name="비고")
    sort_order = models.IntegerField(default=1, verbose_name="정렬 순서", help_text="같은 분류 내 노출 순서")
    use_yn = models.CharField(max_length=1, default='Y', verbose_name="사용 여부", help_text="Y/N")
    created_at = models.DateTimeField(auto_now_add=True, verbose_name="생성일시")
    updated_at = models.DateTimeField(auto_now=True, verbose_name="수정일시")

    class Meta:
        db_table = 'common_code'
        verbose_name = '공통코드'
        verbose_name_plural = '공통코드 목록'
        unique_together = ('large_code', 'medium_code', 'small_code')
        ordering = ['large_code', 'medium_code', 'sort_order', 'code_id']

    def __str__(self):
        return f"[{self.large_code}_{self.medium_code}_{self.small_code}] {self.code_name}"
```
